# UniPred publication preview

`preview.mp4` is a 10.4-second silent loop (960 × 540, H.264) cut from the
UniPred film on the project page (https://unipred.github.io/): the real
robot wiping a table (3× recorded speed) and moving a bottle out of the way
(4×), Tools as a point cloud, the agent-in-the-loop animation as a concept
separates (its latent space is illustrative), and Table Clean in simulation
with the concepts its closed loop perceived tagged on the objects.
`preview-poster.jpg` is a frame of the last shot. `unipred-mark.svg` is
copied unchanged from the project page.
